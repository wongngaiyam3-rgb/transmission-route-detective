# 傳播路線偵探

香港小四科學互動教學網站，配合五張生活情境插圖，探索病原體與傳染病的傳播途徑。

## 活動流程

1. 找出情境中的病原體。
2. 點選或拖放卡片排列傳播路線，再選擇途徑名稱。
3. 選出兩項合適預防方法，解釋在哪一步截斷傳播。

五個情境可自由進入，答錯可重試，支援提示、圖片放大、情境朗讀、瀏覽器進度保存、學習紀錄下載與列印。

## GitHub Pages

使用 main 分支根目錄部署，不需要編譯或伺服器。所有圖片及程式均位於本儲存庫，學生可直接使用公開網站。

進度只保存在目前的瀏覽器，不會自動同步給教師或其他裝置。放大圖中的病原體經過簡化；血液情境示範的是錯誤共用針具，並非正常醫療程序。



## 小科科學問答（2026-11-01）

右上角「召喚小科」以原頁面對話視窗開啟，支援4A–4C／1–25號報到、主題建議、文字提問、關閉／重新開啟、切換學生及手機窄螢幕。問答身分與對話只在目前頁面記憶體保留；切換學生會取消等待中的請求及清除畫面。已被伺服器接受的請求仍可能完成並記錄在原學生名下。每題獨立處理，不傳送聊天歷史或任務答案。

`xiaoke.js` 只呼叫現有科學好奇研究所的公開學生API；不包含任何Gemini金鑰或教師密碼。伺服器原有輸入／輸出審查、失敗停止回答、速率限制及教師登入繼續生效。提問加上「傳播路線偵探」來源標記，供現有教師監察站辨認；這是用戶端來源標記，並非不可偽造的身分認證。

五個任務的本機進度及教學流程保持原樣。小科問答紀錄另存後端，老師可查看最近30天，並非即時求助服務。班別與學號是自選辨識；自動過濾不能保證零漏網，AI科學解說也需要老師核對。
